## 常见问题排查

### 1. 登录后无法跳转到原页面
- **检查**：`checkLogin`函数中的from参数处理
- **解决**：确保URL编码正确处理特殊字符

### 2. 登录状态无法持久化
- **检查**：`app.js`中的`loadStorageData`函数
- **解决**：确认本地存储键名正确（isLoggedIn, loginTime, userInfo等）

### 3. 页面重复跳转登录
- **检查**：各页面的登录检查逻辑是否正确
- **解决**：确保只在必要时调用`checkLogin`

### 4. 退出登录后仍有用户数据
- **检查**：`app.logout`函数的数据清理逻辑
- **解决**：确认所有相关存储键都被清除
